# Нефтекод 2026 — МАС управления производством дизтоплива

Прототип мультиагентной системы для цепочки АВТ → гидроочистка (24-2000):
оценка данных, прогноз качества, оценка тяжести режима, генерация и
Парето-сравнение вариантов управляющих воздействий, объяснимая рекомендация
оператору с Human-in-the-loop подтверждением и мониторингом отклика.

Полное описание архитектуры, допущений и обоснования управляемых параметров —
в [`docs/concept.md`](docs/concept.md).

## Структура проекта

```
config/            (зарезервировано; текущие допущения — в src/oilhack/config.py)
data/raw/           исходные файлы пакета хакатона (не в git, см. ниже)
docs/concept.md     архитектура МАС и все явные допущения
src/oilhack/        код агентов, загрузки данных, харнесса и дашборда
tests/              pytest: формулы ВАК, синхронизация данных, оптимизация, 4 сценария
```

## Установка

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Данные

Положите файлы пакета хакатона в `data/raw/` под именами:

```
data/raw/avt_tags.csv
data/raw/242000_tags.csv
data/raw/lims.xlsx          (ЛИМСы ...xlsx)
data/raw/pak.xlsx           (Выгрузка ПАК ...xlsx)
data/raw/tags_reference.xlsx (Теги_хакатон.xlsx)
```

Эти файлы не хранятся в git (см. `.gitignore`) — они большие и специфичны
для конкретной выдачи хакатона.

## Запуск

CLI-демонстрация одного сценария без дашборда:

```bash
PYTHONPATH=src python3 -m oilhack.harness.runner stable --limit 5
```

Доступные сценарии: `stable`, `quality_risk`, `degraded_data`, `full_cycle`
(описание каждого — в `src/oilhack/harness/scenarios.py` и в `docs/concept.md`).

Дашборд:

```bash
PYTHONPATH=src streamlit run src/oilhack/dashboard/app.py
```

В дашборде: выбор сценария, слайдер по тикам, панели всех агентов, карточка
рекомендации в 7-блочном формате ТЗ, Парето-сравнение сценариев, кнопки
HITL (подтвердить/отклонить/альтернатива) с последующим мониторингом отклика.

## Тесты

```bash
PYTHONPATH=src python3 -m pytest tests/ -q
```

(либо просто `pytest -q` — `pytest.ini` уже прописывает `pythonpath = src`).
Тест `test_scenarios_integration.py` требует наличия `data/raw/*` и
автоматически пропускается, если файлов нет.

## Ключевые допущения (кратко; подробно — в docs/concept.md)

- Значение `307` в телеметрии — код "нет данных" историзатора (обнаружено
  кросс-тегово), а не измерение; маскируется в NaN.
- Приоритет источников серы: ЛИМС (контрольный факт) → ПАК; для серы в
  выданном пакете нет ВАК-формулы, поэтому третьей ступени приоритета нет.
- Границы управляемых параметров — 5-95 перцентиль истории (sentinel-очищенной),
  явно помечены как модельное допущение, а не паспортный предел.
- Действие рекомендуется только когда квалификационный выигрыш по качеству
  или по надёжности превышает заданный порог (`config.QUALITY_MATERIAL_EPS`,
  `config.RELIABILITY_MATERIAL_EPS`) — иначе система намеренно бездействует.
